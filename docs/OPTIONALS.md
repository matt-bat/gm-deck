# Optional upgrades

These are deliberately not preinstalled. Each adds value, but also adds storage,
permissions, host-PC setup, subscriptions, or campaign-specific assumptions.

TTRPG Control Deck 3.1 already includes the offline soundboard, mixed background ambience,
quick/full dice, initiative and HP tracking, current-turn footer, campaign profiles,
session tools, open-rule links, and cached 5e SRD cards. The items below extend
that baseline instead of duplicating it.

## High-value

- **Discord Android app** — native voice/chat on the Echo; heavier than using
  Discord on the PC and the Echo camera is not currently supported.
- **Chrome or Firefox** — a more compatible browser for complex Roll20 pages;
  the included LineageOS browser remains the lightweight default.
- **AutoHotkey + Macro Deck plugin** — multi-step sequences, window focusing,
  launching the whole session, and reliable Foundry/Roll20 profile switching.
- **OBS Studio controls** — scene switching, recording, replay buffer and stream
  status, useful if sessions are recorded or broadcast.
- **VoiceMeeter controls** — separate Discord, music, browser and microphone
  volume buses from the touch panel.

## Foundry enhancements

- **Dice So Nice!** — animated 3D dice.
- **Monk's Common Display** — useful for a player-facing shared display.
- **Token Action HUD** — fast actions without opening character sheets.
- **Tidy UI / system-specific HUD modules** — depends on whether the world uses
  Pathfinder 2e or D&D 5e and must match the Foundry version.
- **Material Deck** — deeper hardware-controller integration; more setup than the
  generic hotkey profile and worth evaluating on the actual Foundry host.

## Atmosphere and table tools

- **Kenku FM** or **Tabletop Audio** routing through Discord.
- A user-provided sound pack copied into a future TTRPG Control Deck update.
- Philips Hue/Home Assistant scene buttons for lights and room ambience.
- Campaign-specific generator packs for regional NPC names, weather, encounter
  complications and treasure beyond the generic offline GM Sparks already installed.

## PC utility

- **KDE Connect permissions** for clipboard, file transfer, media remote and
  touchpad. Grant only the features actually used after pairing.
- Wake-on-LAN and a one-button **Start Session** macro that launches Foundry or
  Roll20, Discord, music and campaign notes and places their windows.
- A shutdown/lock button can be added, but should require a long press to avoid
  ending a session accidentally.
