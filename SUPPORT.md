# Support

## Usage help

For reproducible bugs or documentation problems, open a GitHub issue and include the TTRPG Control Deck version, affected screen, expected behavior, actual behavior, and a screenshot with private campaign details removed.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).

## Optional project support

If TTRPG Control Deck is useful to you, you can optionally [support Matthew Bateman on Ko-fi](https://ko-fi.com/matt0bat). Financial support helps maintain public projects but does not purchase support priority, project control, warranties, special access, or paywalled features.
